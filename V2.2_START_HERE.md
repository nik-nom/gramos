# GramOS v2.2 — About demo/live parity + homepage spacing + Lokseva starter

This is the **same existing Node.js GramOS codebase**, not a new repository or new Supabase project.

## What changed from v2.1

- `/demo/about` and `/v/<village>/about` use the **same** `renderAboutPage` component, classes, grid, spacing and six tabs. A village with no published people or committees now retains the same three-column card slots and committee table shell. Empty slots say that records are not yet published — no demo people are passed off as real village officials.
- **All Information / सर्व माहिती** retains Gram Panchayat information, population, mission and core values, officials, employees, committees and facilities. **History and Roles & Responsibilities are not rendered in All Information.** Responsibilities appear only in tab 6. Existing village data is not deleted.
- Extra About information is displayed as **plain text**, not a narrow card; its images, and any custom image blocks in All Information, are intentionally hidden. Image elements in other About tabs remain supported.
- Homepage Lokseva cards have smaller text and tighter spacing. The video gallery is narrower and shifted left to sit nearer the cards. The navy footer has slightly smaller typography. Header, palette and major section order remain unchanged.
- Lokseva page and admin categories for services, process steps, downloadable public PDF forms and tax payment QR are included for subsequent page refinement; no external payment automation is added.

## Run on your Mac

1. Download the updated `GramOS_v2.2_Node.zip` to Downloads.
2. Stop the previous local server with **Control + C**.
3. Run:

```bash
cd ~/Downloads
unzip -o GramOS_v2.2_Node.zip -d gramos-shamvadi-v2
cd gramos-shamvadi-v2
npm run dev
```

If you also have leftover files from much older versions in this folder, back up the old folder first; the ZIP replaces files with matching names, but unzip does not remove stale files that aren't present in this release.

Open:
- Demo About: <http://localhost:8000/demo/about>
- Real village About: <http://localhost:8000/v/shirpur/about>
- Home: <http://localhost:8000/v/shirpur>
- Lokseva: <http://localhost:8000/v/shirpur/services>
- Admin: <http://localhost:8000/admin/login>

In Safari, hard-refresh with **Cmd + Shift + R**.

## Admin content and real village difference

A real village with no published `content_items` cannot display the demo's sample names/photos. Admin -> `shirpur` -> **About Page — 6 Tabs** lets you edit headings and village information; use **About — Village Facts**, **Officials**, **Committee Sections**, **Committee Members**, **About Facility Tiles**, and **Roles and Duties** to publish real entries.

- All Information will show published facts and other first five categories; it never shows responsibility cards.
- Sixth tab controls its own responsibility cards via the existing **Roles and Duties** content section.
- Village Settings holds real village name/taluka/district information. Each village's records are separate in Supabase.

## Database

The existing `gramos-clean` Supabase project was already extended for V9, V10 and V2.2. It has the `service_steps` and `service_forms` types and `service-documents` public PDF bucket with per-village editor upload/delete policies. **Do not rerun `database/01_setup.sql` or `database/07_lokseva_v22.sql` against the connected project.** The numbered SQL files are source history for provisioning another empty project.

No existing village, administrator or content row is deleted by this UI release.
