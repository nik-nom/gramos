# GramOS v3.0 — News and Gallery

This update adds two Shamvadi-style pages using the existing village data, header, blue announcement bar, and footer.

## Pages
- `/demo/news` — sample news index; `/demo/news/<slug>` — full article.
- `/demo/gallery` — seven-category photo/video/media gallery.
- `/v/<village>/news`, `/v/<village>/news/<slug>`, `/v/<village>/gallery` — the real village equivalents.

## Edit in admin
Log in, open your village, and choose **News — Full Page** or **Gallery — Full Page** from the sidebar. Headings and tab labels can be edited separately in Marathi and English. Use **News** records to add article title, author, date, complete text and photo. Use **Photo gallery** records to upload images, select their section (Meetings / Campaigns / Development / Cultural / Newspaper) and supply captions. Use **Video Gallery** records to upload thumbnails and add a verified HTTPS video link. Publish records when ready.

## Install
**Changed files only:** unzip over your existing v2.9 project root, preserving the directory paths.

**Full project:** unzip into a fresh folder and configure `config.js` or follow the existing `ADMIN_SETUP.md`.

Run `npm test` and `npm run dev`, then test `/demo/news`, `/demo/gallery` and the real village URLs.

## Database
No new tables are required. The existing `content_items` table with `kind='news'`, `kind='gallery'`, `kind='videos'` stores article records and gallery entries. New category lives in `details.gallery_type`, and page labels in `villages.site_settings`. Existing Supabase RLS remains in place. No live content was modified.

## Media optimization
Images uploaded through Admin are compressed to WebP when it reduces size, while preserving quality up to 84%, max side 1920px. Public images use native `loading=lazy` and `decoding=async`. Do not enter real village information in the demo, as it is intentionally separate from published village records.
