# GramOS v2.5 — Column alignment and announcement ribbon

Update to your **existing** Node.js GramOS project. Do not create a new repository, Vercel project, Supabase project, or run old SQL migrations.

## What changed

- **Left column:** the Lokseva title, cards and button now come directly after the Gram Panchayat officials and staff section, using the exact same left-column edges.
- **Right column:** the Video Gallery now comes directly after Live Weather and follows the same right-column width. Each column flows independently, so an empty village does not create a big gap between the staff and Lokseva sections.
- **All pages:** the blue quote/announcement ribbon is now part of the shared public header and appears once, directly below the navigation on the homepage and all inner pages (About, Lokseva, Projects, News, Gallery, etc.). The text moves right-to-left and pauses when hovered; reduced-motion visitors see static text.
- **Admin:** the ribbon continues to use the existing bilingual `quote_mr` / `quote_en` village settings. No new admin controls or database columns are needed.
- **Unchanged:** blue-and-white Shamvadi theme, About tabs, footer, village content, Supabase security, image handling and routing.

## Install the SMALL patch over your previous project

1. Stop the old server: press **Control + C** in Terminal.
2. Download `GramOS_v2.5_Changed_Files_Only.zip` into your Mac Downloads folder.
3. Paste:

```bash
cd ~/Downloads
unzip -o GramOS_v2.5_Changed_Files_Only.zip -d gramos-shamvadi-v2
cd gramos-shamvadi-v2
npm test
npm run dev
```

The changed-files ZIP keeps your existing `src`, `database`, `api`, `assets` and other files.

If you do not already have an up-to-date project folder, download `GramOS_v2.5_Complete_Node.zip` instead and unzip it into an empty directory.

## Publish

Commit the changed files to the **existing GitHub repository**; Vercel then redeploys the same website. Do not run SQL. Your live Supabase data has not been modified by this UI release.
