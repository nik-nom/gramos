# GramOS v4.7 — Navbar, village logo & V Swaraj footer

**Update from:** GramOS v4.6 **Node.js** application. Not the older Next.js 15 app.

## Changes

- Public header matches the supplied Shamvadi screenshot structure: uploaded village emblem, Marathi/English village title and subtitle on the left, all original page links on the right, Marathi/English language menu, one blue announcement ticker below the header.
- Navbar logo belongs to exactly one village. Admin → village → **Navbar logo** lets an editor upload a PNG/JPG/WebP image or provide an HTTPS image URL; adjust its desktop size, mobile size, shape, contain/cover and image position; preview the image; and reset the header image to that village's primary logo.
- Navbar title/subtitle can be edited independently in Marathi/English. Empty fields fall back to the village's name, taluka and district.
- Public footer keeps its **four columns**, from the reference: समाजमाध्यमे, महत्वपूर्ण websites, village pages, village contacts. Links, contact details, social URLs and office hours remain village-scoped; they are reused across all pages of that village.
- Footer bottom-logo band (0–12 logos) remains per village and sits just above the footer, never automatically copied to other villages.
- Company copyright text is fixed for all village sites: `Copyright © 2026 · V Swaraj Gramsoft and Software Private Limited™ · Jalna · 9923227879 / 9423227879`. **MAJHIGRAM TECH/2025** is not added to the template. Super Admin/Editor cannot alter the platform legal text through a village form.
- Responsive design: 4 columns on desktop, 2 on medium devices, 1 on phones; no accidental horizontal scrolling across the offline widths tested (320, 390, 820, 1140, 1526). Mobile navigation is a menu; footer copyright no longer overlaps the fixed back-to-top button.

Existing village content, public reference cards, schemes, PDFs, Supabase table structures, admin roles and user uploads are unchanged.

## Installation and preview

1. Backup the **v4.6** GitHub repository or working folder. Keep the existing `.env` variables and `config.js` pointing at **your** already configured GramOS database.
2. Extract `GramOS_v4.7_Changed_Files_Only.zip` into the **v4.6 project root**, replacing matching files. If unsure of your installed version, use `GramOS_v4.7_Complete_Node.zip` instead (do not merge with the old Next.js project).
3. In macOS Terminal from the project directory:

   ```bash
   npm test
   npm run dev
   ```
4. Open http://localhost:8000/demo and scroll to the footer. On a phone-width browser, verify the mobile menu opens and logo/text stay aligned.
5. Log into `/admin`, select a village, open **Navbar logo**. Upload/replace the image; choose desktop/mobile sizes; use **Save draft** or **Publish navbar logo**. The Reset button restores use of the village's primary logo when you subsequently save.
6. Open **Footer & bottom logos** for that village. Edit its optional social/links, bottom logos, and hours. The platform company line remains locked. Verify a different village is unaffected.
7. Deploy to a Vercel **preview deployment**, test a signed-in image upload and draft/publish flow with the real Supabase database, and only then deploy to production.

## Database

No SQL migration or direct Supabase data writes were performed for v4.7. Changes are stored in existing `villages.site_settings` and existing secure village draft RPC. Platform company identity is a constant in `src/branding.js` (not in the editable village tables).

## Tests and limitations

- `npm test`: 41 automated test scripts passed locally.
- Offline Chromium DOM/CSS render: no horizontal overflow at widths 320, 390, 820, 1140 and 1526 px. Captured reference previews: `gramos_v47_nav_1526.png`, `gramos_v47_footer_1526.png`, mobile 390px equivalents, all in the shared download area.
- Browser navigation to local `localhost` was blocked in this environment; for CSS verification, HTML was rendered offline instead. This does not replace actual authenticated Supabase upload/save/publish testing in staging.
- No deployment was made to Vercel; live pages will stay on the prior version until you deploy this code.
- All copied page content is unchanged; only the fixed company name was corrected to the exact V Swaraj spelling provided in the user's form PDFs.

### Rollback

Restore the prior v4.6 commit/archive in GitHub and redeploy on Vercel. Village database records are not modified by installing this ZIP. If you publish new logo fields after upgrading, they remain in Supabase and can be reset in the admin even after a rollback.
