# GramOS v2.4 — Lokseva / Video Gallery alignment

This is an update to the existing GramOS Node.js website. **No SQL migration is required.**

## What's fixed
- The Lokseva heading and the Video Gallery heading remain at the same top level.
- The video gallery panel height follows the two-row citizen-service card grid.
- The gallery does not pull into the service column or overlap it.
- The `sv-service-column` and `sv-video` remain inside their original DOM hierarchy; admin forms and Supabase field mappings are unchanged.
- Mobile and tablet views retain the single-column order.

## Updating the existing project

```bash
cd ~/Downloads
unzip -o GramOS_v2.4_Changed_Files_Only.zip -d gramos-shamvadi-v2
cd gramos-shamvadi-v2
npm test
npm run dev
```

Open `http://localhost:8000/v/shirpur` and compare with `http://localhost:8000/demo`. In Safari press **Command + Shift + R** to refresh cached CSS.

This does not modify the Vercel site until the updated files are committed and redeployed.
