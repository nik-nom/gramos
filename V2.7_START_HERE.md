# GramOS v2.7 — Lokseva PDF forms + Development Projects

## What changed
- Removed the QR/payment tab from Lokseva; QR codes are not rendered in the public Lokseva page. Legacy database records remain untouched.
- The Lokseva page heading, subtitle, tab names, section headings and labels are editable in Admin -> Lokseva -> Page title and tab headings.
- Service records and downloadable PDF-form records have an **Upload PDF** control. It saves an HTTPS public document URL; save and publish the item after upload. PDF uploads are limited to 5 MB, require a real PDF signature, and use the existing secured `service-documents` bucket. Do not upload confidential documents to this public bucket.
- The Development Projects page now has All/Ongoing/Completed/Upcoming tabs based on the provided Shamvadi reference. Each project can have image, scheme, year, location, status, body, sort order and publication state.
- Admin -> Development Projects edits the exact page headings, tabs, empty-state labels and project-card labels in Marathi/English.

## Run on your Mac
Download the **Changed Files Only** ZIP into Downloads. Stop the existing server with Control+C.

```sh
cd ~/Downloads
unzip -o GramOS_v2.7_Changed_Files_Only.zip -d gramos-shamvadi-v2
cd gramos-shamvadi-v2
npm test
npm run dev
```

Open `http://localhost:8000/v/shirpur/services`, `http://localhost:8000/v/shirpur/projects`, and `http://localhost:8000/admin/login`.

No SQL rerun: the `service-documents` bucket and the permitted `service_links` content type were already created. The projects use existing `projects` records and `site_settings` JSON. Existing village/admin data is unchanged.

## Editing real content
Log in -> select village -> Lokseva (for page text), or Lokseva -> PDF forms and downloads (to upload and publish forms).
For projects: select Development Projects -> Edit project records -> choose Ongoing / Completed / Upcoming -> upload image -> Save -> Publish.

**Demo entries are examples**, not official records. Live village content remains independent.
