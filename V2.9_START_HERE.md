# GramOS v2.9 — Notice Board (नोटीस बोर्ड)

This updates **the existing GramOS Node.js repository** from v2.8; it does not create a new app, hosting project or Supabase database.

## Install on your Mac

1. Stop the currently running GramOS server with `Control + C`.
2. Download `GramOS_v2.9_Changed_Files_Only.zip` into `~/Downloads`.
3. In Terminal run:

```bash
cd ~/Downloads
unzip -o GramOS_v2.9_Changed_Files_Only.zip -d gramos-shamvadi-v2
cd gramos-shamvadi-v2
npm test
npm run dev
```

If your existing project lives elsewhere, replace `gramos-shamvadi-v2` with the folder path containing your project's `package.json`. The ZIP contains relative paths from the project root, so **do not put the extracted `src` folder inside another `src` folder**.

## Pages

- Demo: http://localhost:8000/demo/notices
- Real village: http://localhost:8000/v/shirpur/notices
- Admin: http://localhost:8000/admin/login
- Village Notice Board editor: Admin → Shirpur → **Notice Board — Full Page**
- Notice record editor: Admin → Shirpur → **Notice board** (under Public Website Sections)

## Editing process

1. Open `Notice Board — Full Page` to edit the main title, subtitle, all 4 tab labels, section headings and PDF download-label translations.
2. Click **Add / edit notice or PDF** to create a new record.
3. Enter a title in Marathi and English; choose one category: Notices, Income/Expense Reports, RTI, or Government Resolutions.
4. Optionally enter an event date (YYYY-MM-DD), and enter a short description in the body fields.
5. Click **Upload Notice Board PDF** and choose a publicly shareable PDF up to 5 MB. The form's External Link field is filled when uploading succeeds. Or paste an approved HTTPS PDF link.
6. Save with status `Draft` to work privately or `Published` to display it. The site itself must also have Published status.
7. Open `/v/shirpur/notices`, or use the authenticated `?preview=1` page for unpublished records.

The list is ordered using each record's `sort_order`. Existing notices with no category appear in Notices by default. This preserves legacy content.

**Privacy**: Public PDF uploads are visible to anyone with their link. Do not upload private citizen documents, personal identification, or confidential records here.

## Database

This release needs **no new SQL**. It uses existing `public.content_items` records with `kind='notices'` and `details.notice_type` (`notice`, `financial`, `rti`, or `resolutions`), plus the already configured `service-documents` public PDF bucket with village-scoped authorized uploader policies. The date is in `details.event_date`, and uploaded PDF URL is in `external_url`. We checked the connected `gramos-clean` project: the bucket exists, RLS is enabled, and the Notice Board schema supports these fields. No rows were modified or seeded.

**Demo note**: `/demo/notices` uses example titles and a single placeholder demonstration PDF. It is clearly marked as a sample and does not create village records. The real village shows only its published database records.
