
# GramOS v2.6 – Lokseva View All cleanup

## Update the existing project
1. Stop the previous Node server with Control+C.
2. Download the Changed Files Only ZIP.
3. Run:

```bash
cd ~/Downloads
unzip -o GramOS_v2.6_Changed_Files_Only.zip -d gramos-shamvadi-v2
cd gramos-shamvadi-v2
npm test
npm run dev
```

Open http://localhost:8000/demo/services or http://localhost:8000/v/shirpur/services.

The **All / सर्व पहा** tab has *services + application steps + downloadable forms only*.
The citizen links and QR payment section appear only in their own fifth and sixth tabs.
The links editor appears under Admin > Village > Lokseva > Citizen service links.
Publish each link item to make it public. Draft links remain hidden.

No existing content items or QR settings are removed. No database reset needed.
The database migration `08_services_links_v26.sql` is already applied to the connected
`gramos-clean` project; it should NOT be run again on that project.

The demo's link examples are illustrative. Verify real links before publishing a village website.
