# GramOS v2.8 — Government Schemes / शासकीय योजना

This is an update to your EXISTING GramOS v2.7 Node.js website, not a new project.

## Update locally

1. Stop the running server using Control+C.
2. Download `GramOS_v2.8_Changed_Files_Only.zip` into Downloads.
3. Run:

```sh
cd ~/Downloads
unzip -o GramOS_v2.8_Changed_Files_Only.zip -d gramos-shamvadi-v2
cd gramos-shamvadi-v2
npm test
npm run dev
```

Open the reference demo at `http://localhost:8000/demo/schemes` and your actual village at `http://localhost:8000/v/shirpur/schemes`.

## Admin workflow

1. Log into `http://localhost:8000/admin/login` with your existing Supabase Auth account.
2. Select your village and open **Government Schemes — Full Page** (शासकीय योजना — पूर्ण पान). Edit the title, subtitle, tab labels, section labels, and empty states in Marathi and English. Click **Save scheme page settings**.
3. Select **Government Schemes — Records** (शासकीय योजना — नोंदी), then create or edit a scheme.
4. Give it a title and overview in Marathi/English. Choose **Individual Benefits** or **Public Development**. Optionally edit eligibility, benefits, required documents, how to apply, important notes, and an official HTTPS URL. Enter required documents / eligibility as one item per line.
5. Choose **Published**, save, and refresh your village's public Schemes page. Draft items stay private. Each village is independent.

Only the scheme content and settings you publish appear on the real village site. The demo's example schemes do not get inserted into your Supabase village.

## Database

The existing `public.content_items` table already supports the `schemes` kind, bilingual titles/bodies, ordering, status and village-specific JSONB `details`. The existing `public.villages.site_settings` JSONB column holds all page titles/tab labels. Existing RLS policies continue to protect edits. **No new SQL or new Supabase project is needed.**

## What stays the same

- Shared blue ticker, village header and logo, existing navbar, and navy four-column footer.
- Existing About, Lokseva, Development Projects, Homepage, News, Gallery and admin pages.
- Local Node.js server and existing Vercel setup.
