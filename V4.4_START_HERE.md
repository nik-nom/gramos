# GramOS v4.4 — Fixed About-page reference content

**Update from v4.3. Code-only: no SQL or Supabase data changes required.**

## What is fixed

- The **दृष्टिकोन व ध्येय** and **मूलभूत मूल्ये** boxes include the Marathi reference text visible in the supplied Shamvadi screenshots.
- Eight **भूमिका व जबाबदाऱ्या** cards (सरपंच, ग्रामपंचायत शिपाई, उपसरपंच, पाणीपुरवठा कर्मचारी, ग्रामपंचायत सदस्य, ग्रामरोजगार सहाय्यक, ग्रामपंचायत अधिकारी, संगणक परिचालक) are part of the website renderer, not seeded as editable database rows.
- A new village (even an empty draft) gets the cards automatically in its private website preview, and after publishing in its public About page. Existing villages get the same reusable standard cards without modifying any stored records.
- The default reference bullet sentences cannot be edited or deleted using the admin. Admin → Village → About shows a read-only expandable list of locked reference sections.
- `about_mission_mr/en` and `about_vision_mr/en` remain editable, **but they append optional points** after the locked reference points, instead of replacing them.
- Admin → About → Roles & Duties can create, edit and publish additional responsibility cards. A record with a matching Marathi role title adds extra lines to that original card, without deleting its built-in lines. A new role title creates an additional card.
- Each village still owns all its custom additions. Drafts never become visible without publishing. No content is copied between villages.

## Important distinction: factual details

The screenshot's factual values — Shamvadi village name, population 5,640, household count, dates, PIN/LGD codes and similar statistics — are **not copied into every village**. Those must be entered under the particular village's facts because using another village's values on an official local-government site would be misleading. The *layout and titles* of the information cards are retained.

## Exact scope and evidence

The locked Marathi content in `src/about-reference.js` was transcribed from the **visible** portions of the screenshots attached 21 November 2026. The Gram Panchayat Officer card runs below the bottom of the last provided image; only complete visible bullet lines were copied, rather than inventing cut-off content. The user may supply a full image if additional unseen lines need to be added later.

## Installation

The updated package is the original v4.3 Node.js GramOS project with a small v4.4 change. Do not apply the separate Next.js domain-management update to this project.

1. Make a backup of the existing repository and database.
2. For the changed-files patch, extract the ZIP **into your GramOS v4.3 repository root**, replacing the matching paths.
3. Run `npm test` and `npm run dev`, then visit `/demo/about?tab=duties` and a real village's `/v/<slug>/about?preview=1` as an authorized admin.
4. Test both mobile and desktop layouts, confirm the eight built-in cards and both mission/values boxes appear without any Supabase duty records, then add one custom duty as a draft and publish it.
5. Deploy as a Vercel preview first. Confirm that no new records were inserted in Supabase and there is no duplication.
6. Promote the Vercel deployment only after signed-in preview, publishing and real-domain checks pass.

## Rollback

Re-deploy the backed-up v4.3 source version. This update has **no database migration**, so rollback requires no database edits and preserves all village content and user-added duties.
