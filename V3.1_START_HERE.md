# GramOS v3.1 — Marathi Public Content, News Links, Contact and Footer

## What this update changes

- **Public website text remains Marathi.** The navbar language control can show Marathi or English navigation labels; it no longer translates the entire public body. Admin still supports Marathi/English.
- **News page:** Each headline, photograph and Read button opens a full article. The complete story has an optional external source link (label is editable), up to 8 editable related links, links to other published news, a return-to-news link and a copy-article-link control.
- **Homepage news cards:** Added a visible "संपूर्ण बातमी वाचा" link below article excerpts.
- **Contact page:** New editable 4-tab layout: contact details, Google Maps, social networks and visitor enquiry/complaint form. The address/email/phone come from each village's existing settings. Google Maps embed is optional and URL-restricted. The form remains disabled until Turnstile is configured.
- **Footer:** Four-column blue footer retained. Navigation and official government links work, the headings are clickable, configured social icons link out safely, and a contact link appears when no socials are set. Marathi footer label "समाज माध्यमे" replaces "Social Media".
- **Accessibility and motion:** Light hover/reveal effects, focus styling, responsive mobile layout, reduced-motion support.
- **Data loading:** Normal public visitors now query published records from Supabase; admin previews still load drafts where authorized. Existing image compression and lazy loading remain in place.
- **Database:** A new `submissions.subject` text column stores visitor form categories. It defaults to `general`. No village records or published content are removed; existing Row Level Security is preserved.

## Install the changed-files ZIP (recommended if you have v3.0)

1. Make a backup of your Git repository or current project folder.
2. Unzip **GramOS_v3.1_Changed_Files_Only.zip** **inside the root of the existing GramOS project**, where `package.json`, `src/`, `database/` and `styles.css` live.
3. Do **not** replace your existing `config.js`, `.env` files or Supabase keys.
4. In Terminal:

```bash
cd /path/to/your/gramos-project
npm test
npm run dev
```

5. Open the addresses below in a browser:

- `http://localhost:8000/demo/contact` (Marathi Contact)
- `http://localhost:8000/demo/contact?contactTab=form` (Contact form example; disabled in demo intentionally)
- `http://localhost:8000/demo/news` (News listing)
- `http://localhost:8000/demo/news/clean-village-drive` (Example full news article)
- `/admin/villages/<your-village-id>/contact` (Contact editor, after authenticated admin login)
- `/admin/villages/<your-village-id>/content/news` (Article editor)

If port 8000 is busy, stop the old GramOS server first or run `PORT=8811 npm run dev`.

## Admin editing

**Contact Page editor:** Change the Marathi heading, description, tab names, address/map/social/form section headings, Google Maps link and approved Google Maps embed URL. Village phone/email/street address/social URLs remain under Village Settings.

**News editor:** Add the article title, full Marathi text, author, date, photo, optional PDF/official source URL, optional source-link label, and related links. Each related link goes on its own line as:

```
अधिकृत माहिती | https://maharashtra.gov.in/
शासन निर्णय | https://gr.maharashtra.gov.in/
```

Save the item as **Published** for it to appear on the public site. Each village's content remains separate; this update does not insert demo content into real villages.

**Visitor messages:** Turnstile site key is configured in `config.js`; server-side secret key must be stored in your Vercel environment variables. Do not put server secrets in `config.js`. Messages and optional uploads go through `/api/submit` and remain admin-only under existing Supabase Row Level Security.

## Database upgrade

The additive SQL in `database/09_contact_subject_v31.sql` was applied successfully to the currently connected Supabase project and verified on November 21, 2026. If you install to **a different Supabase project**, run that SQL once in the other project's SQL Editor before deploying the new `/api/submit` endpoint.

`content_items.details` and `villages.site_settings` already use JSONB, so related article URLs, labels and contact map settings require no additional columns. The existing indexes were inspected: redundant indexes were **not** added.

## Deployment

This ZIP updates files locally; it does **not** push to your remote GitHub repository or deploy to Vercel. After testing and confirming the correct repository:

```bash
git status
git add src api database styles.css package.json tests V3.1_START_HERE.md DATABASE_STATUS_V31.md README.md
git commit -m "GramOS v3.1 Marathi contact news and footer"
git push origin main
```

Use the branch connected to Vercel if it is not `main`. Check your Vercel build status, verify the public pages, and test a real submitted message only after Turnstile is configured.

## Tests and safety

`npm test` includes previous version checks plus v3.1 tests for Marathi display, clickable full articles, external URL validation, admin editing, contact settings, mobile-safe layout, safe Google Maps embeds and visitor category input validation. The private Supabase submissions table was verified to retain RLS with no anonymous public SELECT policy.
